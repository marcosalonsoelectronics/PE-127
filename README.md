This video presents another way to modelling the SEPIC converter. In this case, we use the circuit-based modelling technique. This technique uses current- and voltage-depdendent sources to obtain an equivalent averaged model of the converter. This is the same methodology that we saw in early videos like PE #3 (https://youtu.be/gEyCQSS-sOc). 
The equivalent averaged can also be used to calculate the DC operating point of the converter, including the parasitic elements effect. Finally, the circuit can be linearized around the DC operating point to create an equivalent small-signal model from which we can calculate and simulate any transfer function of the converter.
